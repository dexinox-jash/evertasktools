# Social Media Launch Assets — Specs

Use these specs to create launch graphics for Twitter/X, LinkedIn, and Instagram.

- **Format:** PNG or JPEG
- **Content:**

  - Teal gradient background matching app brand
- **Caption suggestion:**

## Instagram Story

- **Size:** 1080x1920 pixels
- **Format:** PNG or JPEG
- **Content:**
  - Full-screen app screenshot or feature graphic
  - "Swipe up" or "Link in bio" CTA
  - Poll sticker: "Do you use voice assistants? Yes / No"

---

## Tips
- Use the same teal color palette across all assets for brand consistency
- Keep text minimal and readable on mobile screens
- Include the app icon so it's instantly recognizable
- Test dark-mode appearance if posting at night
