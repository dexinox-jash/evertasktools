# Phone Screenshots — Capture Guide

Google Play requires **2-8 phone screenshots** in PNG or JPEG format.

## Required Dimensions
- **Minimum:** 320 px (any side)
- **Maximum:** 3840 px (any side)
- **Recommended:** 1080x1920 or 1080x2160 (9:16 or 9:18)
- **Max file size:** 8 MB per image

## Screens to Capture (Suggested Set)

### 1. Empty State
- Screen: Main list with no tasks
- Message: "You're all set"
- Shows the friendly, minimal onboarding feel
- Filename: `01_empty_state.png`

### 2. Voice Input
- Screen: Create Task dialog with the voice input card active
- Shows the microphone icon and waveform
- Highlights the voice-first experience
- Filename: `02_voice_input.png`

### 3. Task List with Subtasks
- Screen: Main list with 1-2 expanded tasks showing subtasks
- Shows progress bars and active subtask highlighting
- Filename: `03_task_list.png`

### 4. Edit Task Dialog
- Screen: Edit Task dialog with subtasks visible
- Shows drag handles, edit fields, and add/remove actions
- Filename: `04_edit_task.png`

### 5. Task Completion Celebration
- Screen: Task Completion Screen with confetti
- Shows "All Done!", stats, and undo button
- Filename: `05_completion.png`

### 6. History Screen
- Screen: History view with archived tasks and aggregate stats
- Filename: `06_history.png`

### 7. Widget Preview (Optional but recommended)
- A framed image showing the EverTask widget on a home screen
- Filename: `07_widget.png`

### 8. Notification Preview (Optional)
- A framed image showing the task reminder notification
- Filename: `08_notification.png`

## Naming Convention
Use this format so they stay ordered in the folder:
```
01_[description].png
02_[description].png
...
```

## Upload Order in Play Console
1. Empty State
2. Voice Input
3. Task List
4. Edit Task
5. Completion
6. History
7. Widget (if captured)
8. Notification (if captured)

## Tips
- Use a device with **Material You dynamic colors disabled** or a static theme so screenshots look consistent
- Screenshot on a **Pixel 7/8 Pro emulator** (1080x2400) for the best-looking Play Store preview
- Make sure the status bar is clean (no low battery, no notification clutter)
- Disable demo mode if using a physical device, or enable it if using an emulator
