# 10-inch Tablet Screenshots — Capture Guide

Google Play allows **0-8 tablet screenshots** per form factor.

## Required Dimensions
- **Recommended:** 1920x1200 or 2560x1600
- **Aspect ratio:** 16:10
- **Max file size:** 8 MB per image

## Screens to Capture (Minimum 2)

### 1. Task List
- Show multiple tasks with clear progress bars
- Filename: `01_tablet10_task_list.png`

### 2. Edit Task Dialog
- Filename: `02_tablet10_edit_task.png`

## Naming Convention
```
01_tablet10_[description].png
02_tablet10_[description].png
```

## Tips
- Use a **Pixel C emulator** or any 10-inch tablet skin
- The app uses Jetpack Compose and should adapt naturally to larger screens
