# 7-inch Tablet Screenshots — Capture Guide

Google Play allows **0-8 tablet screenshots** per form factor. Including them improves tablet discoverability.

## Required Dimensions
- **Recommended:** 1200x1920 or 1080x1920
- **Aspect ratio:** 16:10 or similar
- **Max file size:** 8 MB per image

## Screens to Capture (Minimum 2)

### 1. Task List
- Show the main list with 2-3 tasks side-by-side feel
- Filename: `01_tablet_task_list.png`

### 2. Edit Task Dialog
- Show the edit dialog with room for subtasks
- Filename: `02_tablet_edit_task.png`

## Optional Extras
- Empty state
- History screen
- Widget on tablet home screen

## Naming Convention
```
01_tablet_[description].png
02_tablet_[description].png
```

## Tips
- Use a **Nexus 7 emulator** or any 7-inch tablet skin
- Ensure the app UI scales well (Compose handles this automatically)
